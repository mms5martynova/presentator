# Project memory

## Product intent & audience

- Презентационный инструмент: создание презентаций с предпросмотром результата в виде PDF.
- Имеет бэкенд с API; документация Swagger доступна по адресу `/api/docs`.

## Brand personality & voice

- Технический, практичный тон общения с пользователем на русском языке.

## Visual design & UX direction

- Предпросмотр PDF реализован через открытие в новой вкладке браузера (не через `iframe`).
- В приложении есть кнопка «Предпросмотр».
- `iframe` для отображения PDF из защищённого хранилища избегается — ненадёжён из-за блокировок браузеров/хостинга.

## Decisions, constraints & rationale

- Предпросмотр изменён с встроенного `iframe` на открытие PDF в новой вкладке: `iframe` давал пустой лист из-за блокировок хостинга/браузера для файлов из защищённого хранилища.
- Добавлено SPA-fallback правило маршрутизации для хостинга: без него по прямым ссылкам открывался только Swagger (`/api/docs`), а внутренние страницы приложения — нет.
- Сборка проходит успешно.

## Open questions & assumptions

- Неизвестен конкретный хостинг-провайдер и его конфигурация (правила rewrite/redirect).
- Не указан точный стек бэкенда; Swagger по `/api/docs` suggests наличие серверного API.
- Тип хранилища PDF и механизм доступа не уточнены (защищённое хранилище предполагается).
