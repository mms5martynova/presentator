# Project memory

## Product intent & audience

- Презентационный инструмент «Презентатор»: создание презентаций с предпросмотром результата в виде PDF.
- Бэкенд: Supabase; Swagger-документация API доступна по адресу `/api/docs`.

## Brand personality & voice

- Технический, практичный тон общения с пользователем на русском языке.

## Visual design & UX direction

- Предпросмотр PDF реализован в двух режимах на выбор пользователя:
  - «В маленьком окне» — встроенный просмотр прямо внутри приложения.
  - «Открыть в отдельной вкладке» — PDF в большом окне браузера.
- Для отдельной вкладки пустое окно открывается сразу по нажатию, чтобы обойти блокировку всплывающих окон.
- Кнопки выбора режима адаптированы для мобильных экранов.
- Приложение должно показывать экран входа «Презентатор» или понятное сообщение об ошибке; белый экран / только «Made in Bolt» недопустимы.

## Decisions, constraints & rationale

- Добавлен второй режим предпросмотра (встроенное окно) по запросу пользователя; режим в отдельной вкладке сохранён.
- Ранее предпросмотр был переведён с `iframe` на новую вкладку из-за блокировок хостинга/браузера; теперь оба варианта доступны.
- Добавлена обработка блокировки всплывающих окон для режима отдельной вкладки.
- SPA-fallback правило маршрутизации для хостинга: без него по прямым ссылкам открывался только Swagger (`/api/docs`).
- Белый экран устранён: клиент Supabase создавался без адреса/ключа при отсутствии переменных `VITE_*` в опубликованной версии.
- Поддерживаются два допустимых варианта имён настроек подключения; при отсутствии настроек показывается понятное сообщение.
- Сборка проходит успешно.

## Open questions & assumptions

- Конкретный хостинг-провайдер и его конфигурация (rewrite/redirect) неизвестны.
- Точные имена обоих вариантов переменных `VITE_*` не зафиксированы — поддерживаются оба.
- Механизм доступа к PDF и тип защищённого хранилища не уточнены.
- Надёжность встроенного просмотра «в маленьком окне» на разных хостингах/браузерах не проверена.
