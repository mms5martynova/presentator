# Project memory

## Product intent & audience

- Презентационный инструмент «Презентатор»: создание презентаций с предпросмотром результата в виде PDF.
- Бэкенд: Supabase; Swagger-документация API доступна по адресу `/api/docs`.

## Brand personality & voice

- Технический, практичный тон общения с пользователем на русском языке.

## Visual design & UX direction

- Предпросмотр PDF реализован через открытие в новой вкладке браузера (не через `iframe`).
- В приложении есть кнопка «Предпросмотр».
- `iframe` для отображения PDF из защищённого хранилища избегается — ненадёжён из-за блокировок браузеров/хостинга.
- Приложение должно показывать экран входа «Презентатор» или понятное сообщение об ошибке; белый экран / только «Made in Bolt» недопустимы.

## Decisions, constraints & rationale

- Предпросмотр изменён с встроенного `iframe` на открытие PDF в новой вкладке: `iframe` давал пустой лист из-за блокировок хостинга/браузера для файлов из защищённого хранилища.
- Добавлено SPA-fallback правило маршрутизации для хостинга: без него по прямым ссылкам открывался только Swagger (`/api/docs`), а внутренние страницы приложения — нет.
- Сборка проходит успешно.
- Белый экран устранён: причина — клиент Supabase создавался без адреса/ключа при отсутствии переменных `VITE_*` в опубликованной версии.
- Добавлена совместимость с двумя допустимыми вариантами имён настроек подключения; при отсутствии настроек показывается понятное сообщение вместо падения приложения.

## Open questions & assumptions

- Конкретный хостинг-провайдер и его конфигурация (rewrite/redirect) неизвестны.
- Точные имена обоих вариантов переменных `VITE_*` не зафиксированы в памяти — поддерживаются оба.
- Механизм доступа к PDF и тип защищённого хранилища не уточнены.
